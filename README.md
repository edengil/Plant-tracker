# מעקב צמחים — גרסה חיצונית עצמאית

אפליקציית ווב קטנה ואישית למעקב אחרי צמחי הגינה: תזכורות השקיה ודישון, תוכנית מערכת השקיה עם אזורים, וזיהוי צמחים מצילום. כל הנתונים נשמרים בדפדפן של הטלפון שלך בלבד (localStorage) — אין שרת ואין חשבון.

## איך פורסים (פעם אחת, שתי דקות)

התיקייה הזו מוכנה לפריסה כמו שהיא. שתי האפשרויות הפשוטות:

### Netlify Drop (הכי מהיר)
1. נכנסים ל־[app.netlify.com/drop](https://app.netlify.com/drop) (נרשמים בחינם אם צריך).
2. גוררים את כל התיקייה `plant-tracker-standalone` אל אזור ההעלאה בעמוד.
3. מתקבל קישור קבוע לאפליקציה. זהו — האפליקציה באוויר.

### Vercel
1. מעלים את התיקייה כפרויקט חדש ב־[vercel.com/new](https://vercel.com/new) (או גוררים בעמוד היצירה).
2. לא צריך שום הגדרות בילד — זו אפליקציה סטטית. מאשרים פריסה ומקבלים קישור.

אחרי כל פריסה מחדש (עדכון קבצים), אותו קישור ממשיך לעבוד עם הגרסה החדשה.

## איך מתקינים על הטלפון

1. פותחים את הקישור שהתקבל בטלפון.
2. **אייפון (ספארי):** כפתור השיתוף ← "הוסף למסך הבית" ← אישור.
3. **אנדרואיד (כרום):** תפריט שלוש הנקודות ← "הוסף למסך הבית" / "התקן אפליקציה" ← אישור.

האפליקציה תשב על מסך הבית עם אייקון עלה ירוק, ותיפתח במסך מלא בלי שורת כתובות, כמו אפליקציה רגילה.

## איפה מכניסים את מפתח הזיהוי

הזיהוי מצילום עובד דרך שירות פלנטנט, עם מפתח אישי שלך:

1. אם אין לך מפתח: נרשמים בחינם ב־[my.plantnet.org/signup](https://my.plantnet.org/signup) ומעתיקים את המפתח שמתקבל בלוח הבקרה.
2. באפליקציה: לשונית **הגדרות** (בסרגל התחתון) ← מדביקים בשדה "מפתח זיהוי (פלנטנט)" ← **שמור מפתח**.

המפתח נשמר רק בטלפון שלך. בלעדיו הזיהוי מושבת, אבל הוספת צמחים ידנית עובדת תמיד. את המפתח לא שולחים לאף אחד בצ'אט ולא משתפים — הוא אישי.

## מערכת ההשקיה

במסך **השקיה** נותנים שם למערכת ומגדירים אזורים: ימי שבוע, שעת התחלה, משך בדקות, והאם האזור פעיל. כל צמח אפשר לשייך לאזור (השקיה אוטומטית) או להשאיר ידני עם תזכורות. צמח אוטומטי לא יקפיץ תזכורת השקיה ידנית, ובמסך הבית תופיע ההשקיה הבאה שלו. תזכורות דישון נשארות ידניות לכולם.

שימו לב: האפליקציה רק מתעדת את התוכנית. ההפעלה והשליטה בפועל במערכת נשארות באפליקציית סמארטלייף — אין כאן חיבור חי אליה.

## חשוב לדעת

- הנתונים חיים בדפדפן של הטלפון. מחיקת נתוני הדפדפן, או מעבר לטלפון אחר, תתחיל מרשימה ריקה — לכן מומלץ לייצא גיבוי מדי פעם ממסך ההגדרות ← "גיבוי ושחזור", ולשמור את הקובץ במקום בטוח.
- תמונות צמחים נשמרות בתוך האפליקציה בגודל מכווץ, כדי לשמור על מקום.
- הקבצים בתיקייה: `index.html` (כל האפליקציה), `manifest.webmanifest` (התקנה על מסך הבית), `sw.js` (זמינות גם בלי רשת), `icon.svg` (האייקון).
